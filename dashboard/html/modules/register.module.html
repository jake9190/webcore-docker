Advanced: log in with an instance URL

Connect directly to a Hubitat instance without a registration code. Paste the webCoRE dashboard endpoint URL for your instance (including access_token and hubuid), or paste your dashboard init link.

Advanced: local endpoint

Optional. Route dashboard API traffic directly to your hub or a local reverse proxy instead of the Hubitat cloud. Enter the base URL only (no path), e.g. https://hubitat.domain.com or http://192.168.1.20. Leave blank to use the cloud.
